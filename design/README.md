## Fixed product principles

- AI summary is optional and can always be skipped.
- Text, voice, and TXT/MD file input are supported in the designed flow.
- Skipping summary never changes ticket appearance or selection probability.
- Each station/team can configure its own departure time.
- The time is a grouping reminder, never permission to leave.
- Two or three departure leaders take the social lead; everyone can leave together.
- Work summaries are not visible in the lobby.
- Characters use the cute, loose, flat v0.2 avatar language; avoid semi-realistic portraits.
